   # Job Tracker

   Трекер відгуків на вакансії: список, додавання, статуси.

   **Демо:** https://job-tracker-kappa-nine-22.vercel.app/

   ## Стек
   Angular 22 (zoneless, standalone, OnPush), signals, `httpResource`, `linkedSignal`, Signal Forms, Vitest.

   ## Запуск
   npm install
   npm run start
   npm run test
